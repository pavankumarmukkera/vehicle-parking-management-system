# Power Automate Workflow Example

## Scenario
New business request notification

## Proposed flow

1. Trigger: When a SharePoint list item is created
2. Get the submitted request details
3. Check the request status
4. Send a notification email
5. Record the processing outcome

## Suggested connectors
- SharePoint
- Office 365 Outlook

## Implementation status
Design example only.

This is not a Power Automate export and has not been
deployed or tested in a Microsoft environment.
